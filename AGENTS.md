Proof of Turnover checks vacation-rental cleanings. A cleaner films a 1-2 minute walkthrough on a phone after cleaning, talking as they go (often in Spanish). The app checks every item on the host's checklist (bed made, 4 towels, trash emptied, etc). Rule: an item is only marked done when there is visual proof in a specific frame, confirmed by independent checks: Muse Spark claims it and cites a frame, a second Muse Spark call looks at only that frame, and SAM 3.1 finds and counts the object in that frame. Anything not proven becomes 'needs proof' and the cleaner gets a short re-film request in their language. The host gets a ready / not-ready verdict for the next guest. Every AI model called at runtime must be a Meta model. Runs locally on Windows. Meta Model API: base URL https://api.meta.ai/v1, OpenAI-compatible, key in env var MODEL_API_KEY. Use model muse-spark-1.3-contributor (the hackathon credits only cover contributor variants), sam-3.1, muse-voice-transcribe-1.0. The API sometimes returns 404 model_not_found or an empty model list by mistake; all calls must retry with backoff.
